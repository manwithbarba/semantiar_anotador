# Archivo curado del anotador · Calibración 3

Esta carpeta conserva piezas textuales recuperadas del árbol lógico
`semantiar_anotador_tmp/`. No contiene lotes, notas clínicas, JSON de trabajo,
identificadores personales, credenciales ni binarios.

## Estado documental

- El contrato técnico de la capa léxica procede de un archivo versionado en la
  rama `main` del anotador, inspeccionada en el commit
  `8d74c75d3315698ab156011e0adfd485f10c8fe0`.
- Los documentos específicos de Calibración 3 proceden de la carpeta local
  `anotador calibración 3/`, que no estaba incorporada al Git del anotador en la
  fecha de revisión. Se preservan como **copias documentales candidatas** y
  requieren confirmación humana antes de declararlas protocolo operativo.
- Las rutas de procedencia son relativas al root lógico
  `semantiar_anotador_tmp/`; no se conservan rutas personales absolutas.
