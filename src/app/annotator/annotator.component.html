menu_book Manual de SemantIAr App

Versión tester para uso exclusivamente académico. No constituye software médico y no deben cargarse datos identificatorios de pacientes.

1. Cargá el archivo asignado

Elegí Cargar archivo JSON y seleccioná únicamente el archivo asociado con tu ID de anotador. También podés cargar un JSON de avance para continuar.

2. Revisá cada nota

Leé el texto completo. Aceptá, descartá o ajustá los candidatos e incorporá las menciones omitidas seleccionando su expresión exacta. Usá los accesos Nota, Formas, Conceptos y Cierre para moverte sin desplazamientos largos.

3. Completá formas y conceptos

Resolvé cada forma breve según su contexto, sin adivinar. Para cada concepto clínico, elegí la jerarquía, seleccioná el término SNOMED CT y completá su contexto.

4. Cerrá la nota

Elegí Revisada con conceptos o Sin conceptos anotables. El contador disminuye al cerrar la nota. Si después la modificás, vuelve a pendiente.

5. Guardá el avance

Usá Guardar avance con frecuencia. Conservá el JSON descargado para continuar o enviarlo al responsable del estudio cuando completes todas las notas.
